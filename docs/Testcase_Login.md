## Gợi ý map sang `test_login_page.py`

- Nguồn testcase: file này (`docs/Testcase_Login.md`).
- Code mẫu: `tests/test_login_page.py` (pytest-playwright), POM `pages/login_page.py`, tài khoản mặc định `pages/login_credentials.py` (override: `LOGIN_EMAIL`, `LOGIN_PASSWORD`).
- Mỗi **ログイン-N** tương ứng hàm `test_tc_log_`* trong file test (một số TC gom `parametrize`).
- **ログイン-29:** assert **HTTP 200** từ `account_authentication`; nếu không đạt (vd: 422) test **fail** — cần user hợp lệ cho portal `529/event/3988` hoặc `LOGIN_EMAIL` / `LOGIN_PASSWORD`. Khi fail, ảnh lưu tại `reports/screenshots/` (hook trong `tests/conftest.py`).
